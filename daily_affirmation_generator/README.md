# Daily Affirmation Generator

A simple Python CLI tool that outputs a random positive affirmation each time you run it. Perfect for starting your day with a motivational boost!

## Description

This script displays a random positive affirmation from a curated list of 40 inspiring messages. Each affirmation is designed to promote positivity, self-confidence, and personal growth.

## Features

- 🌟 40 unique positive affirmations
- 🎲 Random selection for variety
- 💻 Simple command-line interface
- 🎨 Formatted output with decorative borders
- ✨ No external dependencies required (uses only Python standard library)

## Requirements

- Python 3.6 or higher

## Installation

1. Clone this repository or download the `daily_affirmation_generator.py` file
2. Ensure Python 3.6+ is installed on your system

## Usage

Run the script from your terminal:

```bash
python3 daily_affirmation_generator.py
```

Or make it executable and run directly:

```bash
chmod +x daily_affirmation_generator.py
./daily_affirmation_generator.py
```

## Example Output

```
=============================================
  I am capable of achieving great things.
=============================================
```

## Use Cases

- Add to your morning routine for daily motivation
- Include in shell startup scripts (.bashrc, .zshrc)
- Set up as a scheduled task/cron job
- Use as a quick pick-me-up during the day
